## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EngagementPlan (LLM output) → real tool dispatch | Every directive.target becomes an argument to a real security tool over SSH against real infrastructure |
| directive → BaseAgent.execute() | Crossing into side-effecting execution; the scope gate is the sole technical authorization enforcement point |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege / Tampering | OmO scope-membership gate | mitigate | Deterministic pre-dispatch set-membership check: target ∈ scope.targets and ∉ scope.exclusions, else reject unless gate_required=True — Critical Failure Mode #1, the one failure mode with direct legal (CFAA) exposure; non-optional |
| T-03-02 | Repudiation / Denial of Service | silent phase failure | mitigate | Every except/timeout in the dispatch loop logs + emits PHASE_FAILED via clawhip; no bare except/pass; per-directive asyncio.wait_for prevents a silent hang (ORCH-01) |
| T-03-03 | Tampering / Denial of Service | hallucinated agent / malformed DAG | mitigate | validate_plan_against_registry + acyclic depends_on check run before directive 1 dispatches — "validate before execute" |
| T-03-04 | Elevation of Privilege | out-of-order / ungated dispatch | mitigate | Directive with unmet depends_on or gate_required=True held until prerequisites read "completed" and gate cleared (exploit-before-verify prevention) |
| T-03-07-inj | Tampering | shell metacharacters in in-scope target | accept | Pre-existing sub-agent f-string injection surface is out of scope (same carve-out as SEC-02); scope gate proves authorization, not string safety (RESEARCH.md Pitfall 7) — documented, not remediated here |
| T-03-SC | Tampering | package installs | accept | No package installs this phase |
