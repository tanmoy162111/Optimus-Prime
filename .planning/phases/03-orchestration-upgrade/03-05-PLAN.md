RESEARCH.md Pattern 1 recommended shape (copy verbatim, plus the GATE_PENDING member added for Plan 08):
  class ClawhipEventType(str, Enum): PHASE_STARTED / PHASE_COMPLETED / PHASE_FAILED / PLAN_REJECTED / GATE_PENDING
  class ClawhipEvent(BaseModel): event_type; directive_id: Optional[str]=None; detail: str=""; error: Optional[str]=None
  class Clawhip:
      def __init__(self, connection_manager, xai_logger): ...
      async def emit(self, session_id, event):
          await self._manager.send(session_id, event.model_dump(mode="json"))
          if event.event_type in (PHASE_FAILED, PLAN_REJECTED, GATE_PENDING):
              self._xai.log_decision(decision_type=event.event_type.value, reasoning=event.detail, confidence=1.0, factors=[event.directive_id or "plan-level"])

GATE_PENDING semantics (D-08 boundary, consumed by Plan 08): a terminal event OmO emits when it reaches a directive with gate_required=True and no mid-dispatch approval mechanism exists in phase 3. It is an auditable boundary condition (hence XAI-logged), signalling the directive needs manual re-issue after operator review — NOT a hang and NOT a silent skip.

research_daemon.py — orphaned; its constructor accepts an optional event_bus: Any = None and treats it as inert. D-10: minimal stub delivery channel, no real listener.
