# Plan 03: Migrate preserved tests and remove dead system

## Objective
This is the closing plan for Phase 1. It depends on Plan 02 (which already deleted the 17 dead-code test files and repointed pytest at `tests/`). Here we:

1. Verify no production module (anything in `backend/` outside `backend/main.py`, `backend/core/`, `backend/agents/`) imports from the soon-to-be-deleted modules — this is the safety check before deletion.
2. Migrate the 9 preserved test files from `backend/tests/` into `tests/` under matching subdirectories (`tests/memory/`, `tests/intelligence/`, `tests/tools/`).
3. For `test_kali_connection_mgr.py` only: remove the two lines that import `backend.core.terminal_broadcaster` (they are inside test bodies, lines 370 and 410 per research) — replace with a stub or simply delete the affected test functions if they cannot stand without `TerminalBroadcaster`. The other 7 preserved files have NO old-system imports (already verified).
4. Delete `backend/tests/` entirely (only `__init__.py` and the 9 source files remain at this point — all are moved or have been processed).
5. Delete `backend/main.py`, `backend/core/`, and `backend/agents/`.
6. Run the full `pytest tests/` and confirm exit 0.
