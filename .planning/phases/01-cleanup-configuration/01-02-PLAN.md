# Plan 02: Delete dead-code tests and repoint pytest at tests/

## Objective
This plan does NOT delete `backend/main.py`, `backend/core/`, or `backend/agents/` — that happens in Plan 03 after we've proven the test surface is clean. Here, we:

1. Delete the 17 `backend/tests/` files that import exclusively from `backend.core.*`, `backend.agents.*`, or `backend.main` (per `01-RESEARCH.md` and a verified grep — all 17 are confirmed to test only dead-code modules with no live-system value).
2. Leave the 10 `backend/tests/` files that test live subsystems intact for reference (they will be inspected in Plan 03 to decide migration vs delete).
3. Update `pyproject.toml` `testpaths` from `["backend/tests"]` to `["tests"]` so the canonical new-system suite is what `pytest` runs by default.
4. Verify `pytest tests/` exits 0.

## must_haves
- [ ] All 17 dead-code test files listed in `files_modified` are absent from disk
- [ ] `backend/tests/test_client_profile.py`, `test_smart_memory.py`, `test_source_adapters.py`, `test_custom_tool_generator.py`, `test_research_daemon.py`, `test_reporter_verification_status.py`, `test_kali_connection_mgr.py`, `test_kali_ssh_timeouts.py`, `test_tor_socks5.py` are still present (9 preserved files plus `__init__.py`)
- [ ] `pyproject.toml` contains exactly `testpaths = ["tests"]` (no `backend/tests` reference)
- [ ] `pytest tests/ -v --tb=short` exits 0
- [ ] `grep -r 'from backend.core\|from backend.agents\|from backend.main\|import backend.core\|import backend.agents\|import backend.main' tests/` returns nothing
